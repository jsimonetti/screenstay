Region rectangles (white) tile exactly and keep their shared edges, so the linked handles survive. windowGap is one number in global settings and is applied to the placed window (blue) at runtime, not stored in the geometry. Overlay regions ignore it, matching the padding: 0 you already set on every Focus region by hand. Gutter exaggerated 8× here.

5  Settled behaviour

AreaDecision
LaunchProfiles tab, with a profile selected. Old region editor stays untouched during development.
ScopeOne overlay per display in the profile, all live at once, shared undo stack.
Unavailable hardwareRefuse with the missing displays named. Any successful profile match counts, not just exact identity.
ModelFlat list of free rectangles, unchanged. Any number may overlap.
Z-orderArray order. Bring to Front / Send to Back. No schema change; runtime is unaffected.
HandlesDerived, not structural. Coincident edges get one linked handle; lone edges get a dim one.
PointerDrag inside to move, drag edge or handle to resize, drag empty space to draw.
MenuEvery discrete action. Header names the target region.
SplitSplit into Columns / Split into Rows, always 50/50. Top-left keeps id, name, apps, shortcut.
GutterPer-region padding removed. One global windowGap, applied at placement, ignored by overlays.
SnappingNo auto-tidy on open. Snap Edge is the explicit way to create shared edges. Drag-time snapping deferred.
SafetyAssignment badge on every region. ⌘Z / ⇧⌘Z. ⎋ prompts, naming what would be lost.
Migrationv2 → v3: drop Region.padding, set GlobalSettings.windowGap = 3. Geometry untouched.
